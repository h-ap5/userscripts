## v1.0.2 — 크랙 순정 스타일 적용 및 사라진 원문 안내

### 🎨 크랙 순정 스타일 적용

* 목록 창·설정·알림의 색을 크랙 사이트의 테마 색상에서 가져와 순정 라이트·다크 화면과 같은 톤으로 표시합니다. 강조색은 크랙 브랜드 색, 글꼴은 Pretendard를 사용합니다.
* 목록 창 제목 옆에 북마크 아이콘을, 검색창 안에 돋보기 아이콘을 넣었습니다. 검색창 안내 문구는 `제목·대화 내용·턴 검색`으로 바꿨습니다.
* 북마크 항목을 카드 모양으로 바꾸고, 왼쪽 색 띠 대신 작은 리본으로 책갈피 색을 표시합니다. 턴 번호는 앞쪽 배지로 보여 줍니다.
* 제목을 따로 정하지 않은 북마크는 제목과 미리보기 첫 줄이 같은 글로 두 번 보이지 않도록, 제목 자리에 저장한 날(`오늘 저장`, `9월 27일 저장` 등)을 표시합니다.
* `원문 이동 ↗`을 `원문으로 이동`과 화살표 아이콘으로 바꿨습니다. 삭제 버튼은 평소 다른 버튼과 같은 색이고, 마우스를 올렸을 때만 빨간색으로 표시합니다.
* 설정의 ON/OFF 글자를 스위치로 바꾸고, 색상 선택을 원형 견본과 체크 표시로 정리했습니다. 설정을 여는 동안에는 톱니 버튼이 눌린 상태로 표시됩니다.
* 알림은 화면과 반대 톤(라이트 모드에서는 어둡게, 다크 모드에서는 밝게)의 토스트로 바꾸고, `중단` 같은 알림 버튼은 강조색으로 표시합니다.
* 원문으로 이동했을 때의 강조 테두리를 크랙 강조색으로 바꾸고, 한 번 퍼지는 효과를 넣었습니다.
* 창 열기·알림·리본에 짧은 애니메이션을 넣었습니다. 기기에서 '동작 줄이기'를 켜면 애니메이션은 모두 꺼집니다.
* 터치 화면에서는 창 위쪽 버튼과 항목 버튼의 터치 영역을 44px로 넓혔습니다.

### 🧭 사라진 원문 안내

* 저장한 턴의 앞뒤(5턴 이내)를 모두 불러왔는데도 원문이 없으면 계속 찾지 않고 `이 북마크의 원문이 지금 대화에 없어요. 리롤·수정·삭제되었을 수 있어요.`라고 알려 줍니다.
* 같은 턴에 같은 역할의 버블이 있으면 알림의 `N턴으로 이동` 버튼으로 그 버블로 바로 이동할 수 있습니다.
* 턴 번호가 없는 북마크는 기존처럼 사용자가 중단할 때까지 계속 찾습니다.
* 탐색 중 표시되는 턴 범위에 턴 번호가 없는 버블이 `0턴`으로 섞여 `0~N턴`처럼 보이던 문제를 수정했습니다.

### ⚡ 긴 대화 성능 개선

* 버블의 글·턴·역할을 한 번 읽어 두고, 내용이 바뀐 메시지만 다시 읽습니다. 과거 로그가 많이 쌓여도 새로 온 버블만 처리합니다.
* 대화상자·메뉴가 화면을 가리는지 확인하는 검사는 스크롤이 이어지는 동안 잠깐 재사용하고, 버블 모양·역할은 다시 스캔할 때만 구합니다.
* 다른 확장 프로그램 창·입력칸 제외 검사와 스크롤 영역 계산에서, 버블들이 함께 쓰는 상위 영역은 한 번씩만 확인합니다.
* 값이 같은 표시 상태·속성은 다시 쓰지 않아, 이 스크립트와 다른 확장 프로그램의 화면 감시가 불필요하게 깨어나지 않습니다.

### ✅ 기존 기능 유지

* 북마크 저장 형식, 색상·표시 설정, 입력창 리본과 원문 이동 방식은 그대로입니다.
* 외부 서버 전송이나 API 호출 없이 동작하는 구조도 유지합니다.

## v1.0.1 — 대화 감지 및 오래된 북마크 탐색 최적화

### ⚡ 상시 감시 부하 감소

* 페이지의 모든 변화를 같은 방식으로 다시 처리하지 않고, 메시지·입력창·레이아웃에 영향을 주는 변경만 구분해 반영하도록 개선했습니다.
* 북마크 자체 UI가 만든 DOM 변경과 스크롤은 다시 검사 대상에서 제외했습니다.
* 스트리밍 중 이어지는 글자 변경은 조용해진 뒤 합쳐 처리하며, 긴 답변도 최대 1.2초 간격으로 상태를 반영합니다.
* 북마크 버튼 상태를 연결할 때 매번 전체 목록을 재검색하지 않도록 메시지별 조회표를 사용합니다.
* CSS 위치 복구 및 SPA 안전 점검 주기를 완화하고, 일반적인 스크롤·리사이즈·DOM 변경은 기존처럼 즉시 반영합니다.

### 🧭 오래된 북마크 이동 안정화

* 90초 또는 100회 뒤 자동으로 포기하던 제한을 제거했습니다. 사용자가 중단하거나 방을 이동하지 않는 한 과거 대화를 계속 불러옵니다.
* 현재 불러온 턴 범위를 탐색 알림에 표시해 진행 상태를 확인할 수 있습니다.
* 가상 목록의 경계에서 로딩이 멈춘 경우 지연 로더를 다시 깨우며 탐색을 이어갑니다.
* 재접속 후 메시지·그룹 ID가 달라져도 저장된 턴, 역할, 정확한 본문이 유일하게 일치하면 같은 북마크로 복구합니다.
* 후보가 여러 개인 경우에는 임의로 다른 리롤 답변을 선택하지 않는 기존 안전 원칙을 유지합니다.

### ✅ 기존 기능 유지

* 색상별 북마크, 턴 이동, 유저 버블 표시, 좌우 반전, 입력창 리본, 3줄 미리보기와 로컬 저장 형식은 변경하지 않았습니다.
* API와 인증 정보에 접근하지 않는 구조도 그대로 유지합니다.
