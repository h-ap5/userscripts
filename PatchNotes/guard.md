## v1.2.8 — 설정창 개편 및 라디오존데 위 배치

### 🪟 설정창 전면 개편

* 크랙 기본 메뉴와 같은 목록형 설정창으로 새로 만들었습니다.
* 상단에 현재 상태를 색상 점과 함께 표시합니다.

  `전송 가능` · `한 번 더 가능` · `전송 차단됨` · `확인 중` · `확인 필요` · `감시 꺼짐`

* 사용량 게이지에 멈춤 구간(띠)과 목표 지점(세로선)을 함께 표시합니다. 상한을 넘겨 쓴 경우에도 넘친 양이 보이도록 게이지 눈금을 자동으로 늘립니다.
* `오늘 사용량 · 목표 · 멈춤 구간`을 한 줄로 요약하고, 그 아래에 멈춤 구간까지 남은 양이나 차단 사유를 안내합니다.
* 설정 항목을 `감시`, `일일 목표`, `허용 오차`, `재생성도 막기` 순으로 정리했습니다.
* `지금 확인` 항목에 마지막 확인 시각과 합산한 내역 건수를 함께 표시합니다.

### 💾 설정 즉시 적용

* `설정 저장` 버튼을 없애고, 바꾼 설정을 바로 적용합니다.
  * `감시`, `재생성도 막기` 스위치는 누르는 즉시 저장됩니다.
  * 숫자는 `−` / `+` 버튼, Enter, 입력칸 밖 클릭 중 어느 방식으로든 바로 저장됩니다.
* `−` / `+` 버튼과 키보드 `↑` / `↓`로 일일 목표는 100개, 허용 오차는 50개 단위로 조절합니다. (`1,037`에서 `+`는 `1,100`, `−`는 `1,000`)
* `1,500`, `1500개`, `±200`처럼 입력해도 숫자만 읽고, 천 단위 쉼표로 표시합니다.
* 잘못된 값은 입력칸에 빨간 테두리와 이유를 표시하고, 입력칸을 벗어나면 이전 값으로 되돌립니다.

### ⌨️ 설정창 조작 개선

* 설정창 바깥을 누르면 닫히며, 입력 중이던 숫자는 적용됩니다.
* `Esc`로도 닫을 수 있습니다. 숫자를 입력하던 중에는 첫 `Esc`가 입력값을 되돌리고, 한 번 더 누르면 닫힙니다.
* 설정창 안에서 누른 키가 크랙 단축키(Enter 입력창 이동 등)로 전달되지 않도록 막았습니다.
* 키보드로 열면 첫 항목에 초점이 가고, 닫기 버튼이나 `Esc`로 닫으면 가드 상태 행으로 돌아옵니다.
* 터치 화면에서는 항목과 버튼의 터치 영역을 넓혔습니다.

### 🛰️ 라디오존데 위로 가드 이동

* 라디오존데 사용 시 배치 순서를 다음과 같이 바꿨습니다. CSP 테마 확장 사용 여부와 관계없이 동일합니다.

  `가드 → 라디오존데 점수판 → 채팅 입력창`

* 설정창과 알림은 가드 바로 위에 열려 라디오존데와 겹치지 않습니다.
* 라디오존데 줄이 두 줄로 접히거나 펼쳐질 때, 숨겨졌다 다시 나타날 때도 가드가 그 위를 따라갑니다.
* 입력창 위에 다른 줄(추천 답변 등)이 붙어 있으면 그보다 위에 표시합니다.
* 가드의 좌우 폭과 위치를 입력 박스 테두리에 맞췄습니다.
* 라디오존데가 입력창 위에 겹쳐 그려지는 환경(단독 라디오존데)에서만 입력창 영역을 가드 한 줄만큼 늘리고 라디오존데를 함께 내립니다. 그 밖의 환경에서는 기존 여백을 사용해 레이아웃을 건드리지 않습니다.

### 🎨 크랙 순정 스타일 적용

* 가드 상태 행, 설정창, 알림이 크랙 자체 색상과 글꼴을 사용해 순정 다크·라이트 화면과 같은 톤으로 표시됩니다.
* 크랙이 `body`에 표시하는 다크·라이트 모드를 직접 읽어 모드 전환을 바로 따라갑니다.
* 테마 확장프로그램이 입력창을 꾸민 경우 설정창과 알림도 입력창의 바탕·테두리·글자색을 따르고, 뒤 글자가 비치지 않도록 불투명도와 흐림을 보강합니다.
* 감시를 끈 상태는 회색, 한 번 더 허용되는 상태는 크래커색으로 상태 점을 구분합니다.

### 💬 안내 문구 정리

* `허용 범위`, `정지 구간` 등으로 섞여 있던 표현을 `멈춤 구간`으로 통일했습니다.
* 목표 개수에 닿아 차단되면 `오늘 1,020개로 목표 1,000개에 닿았어요.`처럼 전용 안내를 표시합니다.
* 마지막 확인 시각을 초 단위 없이 24시간제(`14:05`)로 표시합니다.

### 🛡️ 기존 동작 유지

* 오늘 사용량 합산 방식, 일일 목표·허용 오차에 따른 차단 기준, 사용량 자동 갱신 주기는 기존과 동일합니다.
* Enter·전송 버튼·폼 제출·재생성 차단 동작은 기존과 동일합니다.
* 기존에 저장한 설정은 그대로 이어서 사용됩니다.

## v1.2.7 — 상시 감시 및 사용량 갱신 최적화

### ⚡ 페이지 부하 감소

* 채팅 입력창과 무관한 페이지 변경은 가드가 다시 검사하지 않도록 DOM 감시 범위를 좁혔습니다.
* UI 위치 계산을 프레임당 한 번으로 합쳐, 스트리밍과 다른 확장프로그램의 화면 갱신 중 중복 계산을 줄였습니다.
* UI 상태 확인 주기를 완화하고, 방 이동 또는 가드가 실제로 분리된 경우에만 다시 연결하도록 변경했습니다.
* 서울 날짜와 갱신 시각의 포맷터를 재사용해 반복 생성 비용을 줄였습니다.

### 🔄 사용량 조회 효율 개선

* 숨겨진 탭과 채팅방 밖에서는 주기적인 사용량 조회를 멈추고, 다시 돌아왔을 때 필요한 경우에만 재개합니다.
* 반복 타이머를 다음 조회 예약 방식으로 변경해 느린 네트워크에서도 조회가 서로 겹치지 않도록 했습니다.
* 포커스·탭 복귀 이벤트가 연속으로 발생해도 짧은 시간 안에는 한 번만 처리합니다.
* 이미 최신 사용량을 받은 직후의 중복 자동 조회는 생략합니다.

### 🛡️ 기존 보호 동작 유지

* 수동 새로고침과 메시지 전송 후 확인은 강제 조회로 유지됩니다.
* 조회 중 들어온 수동 갱신은 사라지지 않고 현재 요청이 끝난 뒤 한 번 이어서 실행됩니다.
* 일일 한도 차단, 안전 여유분, Enter·전송 버튼·폼 제출·재생성 차단 및 라디오존데/CSP 배치는 기존과 동일합니다.
* 메타데이터와 내부 표시 버전을 `1.3.0`으로 통일했습니다.

## v1.2.6 — 채팅 감지 및 UI 레이어 개선

### 🎯 입력창 감지 정확도 개선

* 가드가 Crack의 실제 채팅 입력창에서만 작동하도록 범위를 제한했습니다.
* 댓글 입력창, 제작 프롬프트, 검색창, 제목·설명 입력창 등을 채팅창으로 오인하던 문제를 수정했습니다.
* Enter 전송, 전송 버튼, 폼 제출, 다시 생성 차단이 모두 현재 활성화된 채팅 입력창에만 적용됩니다.
* 모달·다이얼로그·사이드 패널 내부의 입력 요소에는 가드가 표시되거나 개입하지 않습니다.

### 🧱 사이드바 레이어 문제 수정

* 가드 UI를 페이지 최상단의 고정 오버레이에서 실제 채팅 영역 내부 레이어로 이전했습니다.
* 사이드바가 열리면 가드가 사이드바 위로 삐져나오지 않고 자연스럽게 가려집니다.
* 채팅 입력창이 재생성되거나 화면 구조가 변경돼도 가드가 새 입력창 위치에 다시 연결됩니다.

### 🛰️ 라디오존데·CSP 테마 확장 호환성

* CSP 테마 확장 사용 여부와 관계없이 다음 배치 순서를 유지합니다.

  `라디오존데 점수판 → 가드 → 채팅 입력창`

* 점수판과 가드, 입력창 사이의 간격을 일정하게 통일했습니다.
* 가드가 점수판이나 입력창과 겹치지 않도록 필요한 공간을 자동으로 확보합니다.
* 라디오존데와 가드가 사이드바 아래에서 동일한 방식으로 가려지도록 레이어 구조를 통일했습니다.

### 🪟 설정창 및 알림 표시 개선

* 설정창이 라디오존데 점수판에 가려지지 않도록 점수판 위쪽으로 자동 배치됩니다.
* 화면 높이에 맞춰 설정창의 최대 높이를 자동 조절하고, 필요한 경우 내부 스크롤을 사용합니다.
* 설정 저장 알림의 높이까지 계산해 제목이나 초록색 완료 알림이 화면 위에서 잘리던 문제를 수정했습니다.
* 설정창이 닫힌 상태에서 표시되는 차단·새로고침 알림도 점수판과 겹치지 않습니다.
* 모바일 화면에서도 계산된 안전 높이가 유지되도록 최대 높이 처리를 개선했습니다.

### 🎨 UI 디자인 통일

* 순정 Crack 사용 시 입력창의 배경색, 테두리, 블러 효과와 둥근 모서리를 가드에 그대로 반영합니다.
* CSP 테마 사용 시에도 해당 테마가 적용한 실제 모서리와 표면 스타일을 유지합니다.
* 비대칭 모서리를 포함한 계산된 테두리 모양을 그대로 복제합니다.

### ⚙️ 안정성 개선

* 가드 표시, Enter 차단, 폼 제출 차단 및 전송 버튼 감지가 하나의 검증된 채팅 컨텍스트를 공유하도록 변경했습니다.
* 페이지 이동이나 React 재렌더링으로 입력창 DOM이 교체되는 상황의 재연결 처리를 보강했습니다.
* 불필요하게 사이트 요소의 `position`이나 전역 `z-index`를 덮어쓰지 않도록 변경해 레이아웃 충돌 가능성을 줄였습니다.
* CSP 테마 활성화·비활성화, 라디오존데 사용, 사이드바 표시 환경에서 배치 및 레이어 동작을 검증했습니다.

## v1.2.3 ~ v1.2.5 업데이트

### 🖥️ 순정 크랙 UI 지원

기존에는 일부 UI 탐색이 테마 확장프로그램의 `data-sgb-*` 구조에 의존해, 테마 확장프로그램이 없는 환경에서 크래커 가드가 표시되지 않는 문제가 있었습니다.

* 순정 크랙의 메시지 입력창 자동 탐색 추가
* 테마 확장프로그램이 없어도 가드 정상 표시
* 순정 환경에서도 전송 버튼·Enter 전송·재생성 차단 정상 작동
* 테마 확장프로그램이 설치된 경우 기존 연동 방식 우선 유지

### 📍 가드 표시 위치 개선

순정 크랙에서 가드가 입력창 상단 테두리에 걸쳐 표시되던 문제를 수정했습니다.

* 순정 UI에서는 입력창 바로 위에 자연스럽게 표시
* 테마 확장프로그램 사용 시 기존 위치 유지
* 화면 크기 및 입력창 위치 변화에 따라 자동 재배치

### 🛰️ 라디오존데 호환 개선

순정 크랙과 라디오존데만 함께 사용할 경우 두 확장프로그램의 표시 영역이 겹치던 문제를 수정했습니다.

현재 아래 조합을 모두 지원합니다.

* 순정 크랙
* 순정 + 라디오존데
* 테마 확장프로그램
* 테마 확장프로그램 + 라디오존데

라디오존데가 감지되면 실제 표시 위치를 기준으로 가드 영역을 자동 조정해 서로 겹치지 않도록 개선했습니다.

### 🔧 기타

* 크랙 자체에서 발생하는 일부 `404` 및 Shiki 관련 `403` 콘솔 오류가 크래커 가드와 무관한 오류임을 확인
* 기존 크래커 사용량 집계 및 일일 목표 차단 로직은 그대로 유지
* 다양한 확장프로그램 조합에서도 독립적으로 동작하도록 UI 의존성 완화
