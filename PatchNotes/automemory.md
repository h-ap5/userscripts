## v2.4.0.2

### 화면 정리

* 설명을 칸마다 `ⓘ`로 옮겼습니다. 누르면 짧은 안내가 열리고, 다른 곳을 누르거나 Esc를 누르면 닫힙니다.
* `자동 장기기억 정리`의 긴 설명문을 없애고 꼭 알아야 할 주의 3줄만 남겼습니다. 숫자 칸 이름도 `실행 주기`·`한 번에 읽기`·`최근 제외`·`참고 기억`·`중간 병합`·`전체 유지 상한`·`압축 후 목표`로 줄였습니다.
* `상단 요약 버튼 표시` 줄을 없애고 `턴 수` 옆 `상단 버튼` 칸으로 옮겼습니다. 꺼도 사이드바 메뉴로 열 수 있다는 안내는 `ⓘ`에 있습니다.
* 파란색 버튼을 없앴습니다. `2차 압축`·`지금 실행`은 다른 버튼과 같은 모양이고, 2차 압축 창의 `압축 생성`은 검정 주 버튼입니다. 파란색은 수정된 카드처럼 상태 표시에만 씁니다.
* 입력칸·드롭다운·버튼 높이를 맞췄습니다. `1차 요약`·`기본 프롬프트`·`프롬프트 편집`이 같은 높이로 나란히 놓입니다.
* 글자 크기를 창 제목·구역 제목·본문·보조 글·배지 다섯 단계로 통일했습니다.

### 수정

* 제목에 큰따옴표(`"`)가 들어간 장기기억이 `장기기억 편집` 창에서 빈 제목으로 보이던 문제를 수정했습니다.
* 덮어쓰기 복원과 일괄 편집 저장이 수정·삭제 요청을 쉬지 않고 연달아 보내던 것을 카드 추가와 같은 간격으로 나눠 보내도록 바꿨습니다.
* 여러 방이나 여러 페이지를 이어 읽을 때 요청 사이에 짧은 간격을 둡니다.

## v2.4.0

### 장기기억 이식

* AI 요약 창 하단에 `이식·백업·복사` 버튼을 추가했습니다. `방 이식`·`백업 · 복원`·`주석 복사` 탭으로 나뉘며, 마지막에 사용한 탭으로 열립니다.
* `보내기`는 현재 방의 장기기억을 선택한 여러 방에 복사하고, `가져오기`는 선택한 방의 장기기억을 현재 방으로 가져옵니다.
* 채팅방 목록은 같은 작품의 방을 먼저 표시하며, `모든 작품`으로 전체 방을 보거나 방 제목·작품명으로 검색할 수 있습니다.
* 실행 전 `미리보기`에서 방마다 추가될 카드 수와 이미 있어 건너뛸 카드 수를 확인할 수 있습니다.
* 제목과 본문이 같은 카드는 건너뛰고, 오래된 카드부터 추가하여 원래 순서를 유지합니다.
* 복사된 카드는 대상 방에서 `[추가]` 카드가 되며, 크랙의 `[추가]` 카드 100개 한도를 넘게 되는 방은 건너뜁니다.
* 도중에 실패해도 이미 추가된 카드는 그대로 남으며, 다시 실행하면 이미 있는 카드는 건너뛰고 나머지만 추가합니다.
* 한 방에서 요청 오류가 나면 그 방만 실패로 표시하고 나머지 방은 계속 진행합니다.
* 이식 중에는 자동 장기기억 정리가 실행되지 않으며, 자동 정리 저장이 끝나지 않은 방과 다른 탭에서 작업 중인 방은 건드리지 않습니다.

### 백업 · 복원

* `백업 파일 받기`로 현재 방의 장기기억 전체와 단기 기억·관계·목표를 JSON 파일 하나로 저장합니다.
* 서버 백업, AutoMemory 내보내기 파일(JSON·TXT·Markdown), 기존 longTerm 백업 파일을 불러올 수 있습니다. 복원은 장기기억에만 적용합니다.
* 파일을 선택하면 적용 전에 현재 서버 내용과 비교한 결과를 표시합니다.
* `추가 복원`은 서버에 없는 카드만 추가하고, `덮어쓰기`는 파일 내용에 맞춰 기존 카드를 수정·추가·삭제합니다.
* 덮어쓰기를 실행하기 전에 현재 서버 내용을 백업 파일로 먼저 내려받습니다.
* `[추가]` 카드는 덮어쓰기에서 기본으로 보호되며, `덮어쓰기에서 [추가] 카드도 바꾸기`를 켜면 함께 파일 내용에 맞춥니다.
* 적용이 끝나면 서버 목록을 다시 읽어 모든 변경이 반영되었는지 확인합니다.

### 주석 복사

* 선택한 장기기억을 투명 주석 형식 `[주석 문구]: # ( … )`으로 클립보드에 복사하는 기능을 추가했습니다.
* 오래된 카드부터 이어 붙이며, 주석이 깨지지 않도록 제목·본문의 `#` `(` `)`를 `T` `/` `/`로 바꾸고 빈 줄을 한 줄로 합칩니다.
* 주석 문구를 직접 수정할 수 있으며, 마지막으로 사용한 문구를 기억합니다.
* 복사하기 전에 선택한 카드 수와 복사할 글자 수를 표시합니다.

### 순정 블렌드 테마

* 모든 창의 색을 크랙 화면과 같은 색·선·글자 단계로 변경했습니다.
* 주 버튼은 크랙처럼 라이트 모드에서 검정, 다크 모드에서 흰색으로 표시합니다. 선택 표시는 크랙 브랜드 빨강, 보조 버튼은 파랑을 사용합니다.
* 상단 요약 버튼이 크랙 헤더 아이콘과 같은 색을 따라갑니다.
* 작은 글자의 명암을 높여 가독성을 개선했습니다.
* 라이트·다크 모드는 기존처럼 크랙 설정을 따라 자동으로 바뀌며, 버튼·카드의 움직임은 기존과 동일합니다.

### Firebase Gemini 3.8 Flash 지원

* Firebase 모델 목록에 `Gemini 3.8 Flash`를 추가했습니다.
* 낮음·보통·높음 추론 단계를 지원합니다.

### 수정

* `추가하기`로 장기기억을 저장할 때 크랙 웹과 같은 방식(`longTerm`)으로 요청하도록 수정했습니다.

## v2.3.8

### 요약 버튼·사이드바 메뉴 위치 안정화

* 상단바를 화면 좌표 대신 페이지 구조로 찾도록 변경하여, 스크롤·주소창 접힘·제목창 접기와 관계없이 버튼이 같은 자리를 유지합니다.
* 화면 크기 변경 등으로 보이는 상단바가 바뀌면 숨겨진 이전 상단바가 아닌 현재 상단바로 버튼을 옮깁니다.
* 답변 본문과 메시지 목록 안의 툴바도 상단바 후보에서 제외했습니다.
* 상단바를 찾지 못하면 위치가 불확실한 다른 툴바로 옮기지 않고, 상단바가 나타나면 다시 표시합니다.
* 다른 확장프로그램이 상단바나 사이드바에 버튼·메뉴를 추가해도 요약 버튼과 `AI 요약·메모리` 메뉴가 서로 자리를 다투지 않도록 수정했습니다.

### 채팅방 이동 감지 및 성능 개선

* 화면 변화 없이 주소만 바뀌는 채팅방 이동도 1초 안에 감지하여 버튼과 자동 정리 상태를 새 방 기준으로 전환합니다.
* 다른 탭에서 돌아오거나 뒤로 가기로 페이지가 복원되면 버튼 위치와 채팅방 정보를 다시 확인합니다.
* 페이지 전체의 스타일 변화 감시를 상단바·사이드바 주변으로 좁혀, AI 답변이 출력되는 동안의 불필요한 작업을 줄였습니다.
* 백그라운드 탭에서는 버튼 위치를 다시 찾지 않습니다.

## v2.3.7

### 전체 장기기억 유지 상한 수정

* `최대 슬롯`의 5~20개 고정 제한을 제거하고 사용자가 입력한 값을 그대로 적용하도록 변경했습니다.
* `최대 슬롯`을 `전체 장기기억 유지 상한`으로 변경했습니다.
* `전체 압축 목표 슬롯`을 `압축 후 전체 카드 목표`로 변경했습니다.
* 보호된 `[추가]` 카드도 전체 유지 상한의 개수에 포함된다는 설명을 추가했습니다.
* 플랫폼의 `[추가]` 카드 100개 제한과 자동 정리의 유지 상한을 별개의 기준으로 처리합니다.

### 숫자 입력값 처리 개선

* 실행 주기, 한 번에 읽기, 최근 제외, 참고 장기기억, 중간 병합의 고정 최댓값을 제거했습니다.
* 직접 요약 턴 수를 포함하여 사용자가 입력한 유효한 정수를 임의로 줄이거나 다른 값으로 변경하지 않습니다.
* 기존 저장값 `5`를 `10`으로 바꾸던 구버전 보정과 최초 대화 조회의 숨은 500개 상한을 제거했습니다.
* 참고 장기기억 `0`은 추가 참고 없음, 중간 병합 `0`은 기능 끔으로 정확하게 처리합니다.
* 사용할 수 없는 숫자는 몰래 기본값으로 실행하지 않고 입력 오류를 안내합니다.

### 압축 오류 안내 개선

* 보호 카드, 자동 관리 가능 카드, 전체 카드와 설정된 유지 상한을 오류에 표시합니다.
* 압축에 필요한 최소 유지 상한과 사용자가 조정해야 할 값을 구체적으로 안내합니다.

## v2.2.9 

## 자동 장기기억 정리
- 지정한 대화턴마다 AI가 새 로그를 자동 정리하는 기능 추가
- 기본 실행 주기와 한 번에 읽을 분량을 10대화턴으로 변경
- 대화턴은 사용자 메시지 1개 + AI 답변 1개를 한 세트로 계산
- 최신 대화 1턴은 경계가 잘리는 것을 막기 위해 다음 정리로 보류
- 자동 정리 전용 프롬프트를 1차 요약 프롬프트와 분리
- API, 모델, 추론 설정이 자동 정리에도 동일하게 적용되도록 변경
- 최근 장기기억 3~5개를 문맥 참고용으로 전달

- 과거 카드를 매번 전부 재압축하던 구조를 누적형으로 변경
- 기존 독립 장기기억 카드는 평상시에 그대로 보존
- 새 로그가 마지막 사건의 직접 후속일 때만 마지막 카드 수정
- 독립된 사건은 새 assistant 슬롯에 별도 카드로 저장
- 새 assistant 슬롯이 부족하면 기존 카드에 억지로 합치지 않고 로그를 보류
- 슬롯이 나중에 생성되면 보류된 로그부터 자동 처리
- 사용자가 만든 [추가] 카드는 기본적으로 수정·삭제하지 않도록 보호

## 중간·전체 압축
- 중간 병합 주기 설정 추가, 기본 10처리턴
- 중간 병합은 최근 누적 구간에만 적용
- 중간 병합 및 전체 압축에는 활성화된 2차 압축 프롬프트 사용
- 중간 병합 결과 개수는 고정하지 않고 2차 압축 지침이 판단
- 전체 카드가 최대 20개를 초과했을 때만 전체 압축 실행
- 기본적으로 21개가 되는 순간 전체를 목표 16개까지 정리
- 전체 압축 이후 다시 새 카드를 누적하는 구조로 변경

## v2.2.5 — Vertex JSON 지원 및 모바일 설정 UI 개선

### ☁️ Vertex JSON 연결 추가

기존 Firebase AI 연결과 별도로, **Google Cloud 서비스 계정 JSON을 이용한 Vertex AI 직접 연결 방식**을 추가했습니다.

### JSON 지원 기능

* API 제공자 목록에 `Vertex JSON` 추가
* Google Cloud 서비스 계정 JSON 인증
* 서비스 계정 JWT 서명 및 OAuth 토큰 자동 발급
* 일반 AI 요약 지원
* 장기기억 2차 압축 지원
* 모델별 추론 설정 지원
* 토큰 사용량 및 예상 비용 표시
* JSON의 `project_id` 자동 사용
* 별도 Project ID 직접 지정 가능
* `global` 및 지역별 Vertex 엔드포인트 지원
* 인증 만료 또는 `401` 응답 시 토큰을 한 번 자동 갱신

### Vertex JSON 입력 방식

Vertex JSON을 선택하면 다음 두 가지 방식으로 서비스 계정 JSON을 등록할 수 있습니다.

* **JSON 입력 (세션)**  
  현재 요약 창에서만 사용하며 창을 완전히 닫으면 폐기됩니다.

* **JSON 저장/교체**  
  userscript 전용 GM 저장소에 보관하여 다음 실행에서도 사용할 수 있습니다.

저장된 JSON 원문은 설정 화면에 다시 표시하지 않습니다.

### Vertex 설정

* **Location**  
  기본값은 `global`입니다.

* **Project ID**  
  비워두면 서비스 계정 JSON의 `project_id`를 자동으로 사용합니다.

* **Gemini 3 계열**  
  Location 설정과 관계없이 지원되는 `global` 엔드포인트로 자동 연결합니다.

### 🔐 서비스 계정 JSON 보호

서비스 계정 JSON에는 장기 개인키가 포함되므로 일반 API Key보다 엄격하게 처리합니다.

* 서비스 계정 JSON을 페이지 `localStorage`에 저장하지 않음
* 저장된 JSON 원문을 페이지 입력창이나 DOM에 다시 표시하지 않음
* 브라우저 전용 입력창을 통해서만 JSON 입력
* 세션 입력과 영구 저장을 명확하게 분리
* 세션 종료 시 JSON과 발급된 토큰을 메모리에서 폐기
* OAuth 및 Vertex 요청 주소를 Google 공식 도메인으로 제한
* JSON, JWT 및 Access Token을 로그나 내보내기 파일에 포함하지 않음
* 저장된 JSON과 토큰을 직접 삭제할 수 있는 버튼 제공

> 서비스 계정 JSON은 장기 자격증명입니다.  
> Vertex AI 전용 서비스 계정을 만들고 필요한 최소 권한만 부여하는 것을 권장합니다.
