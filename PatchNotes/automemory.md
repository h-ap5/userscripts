## v2.2.9 

## 자동 장기기억 정리
- 지정한 대화턴마다 AI가 새 로그를 자동 정리하는 기능 추가
- 기본 실행 주기와 한 번에 읽을 분량을 10대화턴으로 변경
- 대화턴은 사용자 메시지 1개 + AI 답변 1개를 한 세트로 계산
- 최신 대화 1턴은 경계가 잘리는 것을 막기 위해 다음 정리로 보류
- 자동 정리 전용 프롬프트를 1차 요약 프롬프트와 분리
- API, 모델, 추론 설정이 자동 정리에도 동일하게 적용되도록 변경
- 최근 장기기억 3~5개를 문맥 참고용으로 전달

## 누적형 카드 관리
- 과거 카드를 매번 전부 재압축하던 구조를 누적형으로 변경
- 기존 독립 장기기억 카드는 평상시에 그대로 보존
- 새 로그가 마지막 사건의 직접 후속일 때만 마지막 카드 수정
- 독립된 사건은 새 assistant 슬롯에 별도 카드로 저장
- 새 assistant 슬롯이 부족하면 기존 카드에 억지로 합치지 않고 로그를 보류
- 슬롯이 나중에 생성되면 보류된 로그부터 자동 처리
- 사용자가 만든 [추가] 카드는 기본적으로 수정·삭제하지 않도록 보호

## 중간·전체 압축
- 중간 병합 주기 설정 추가, 기본 10처리턴
- 중간 병합은 최근 누적 구간에만 적용
- 중간 병합 및 전체 압축에는 활성화된 2차 압축 프롬프트 사용
- 중간 병합 결과 개수는 고정하지 않고 2차 압축 지침이 판단
- 전체 카드가 최대 20개를 초과했을 때만 전체 압축 실행
- 기본적으로 21개가 되는 순간 전체를 목표 16개까지 정리
- 전체 압축 이후 다시 새 카드를 누적하는 구조로 변경

## 안정성
- 저장 계획을 먼저 기록한 뒤 PATCH → 검증 → DELETE 순서로 처리
- 중간에 새로고침되거나 API가 실패해도 미완료 작업부터 이어서 재개
- 저장이 완전히 검증되기 전에는 대화 처리 기준점을 넘기지 않음
- 슬롯 부족과 정상 대기 상태는 오류 횟수에 포함하지 않음
- 3회 오류로 일시정지될 경우 실제 마지막 오류 원인을 함께 표시
- 자동 처리 중 새 [추가] 카드를 생성하지 않고 기존 assistant 슬롯만 치환
- 불필요한 10초 전체 로그 반복 조회를 제거하고 새 응답 중심으로 확인
- 슬롯 대기 중에는 장기기억 슬롯만 별도로 재확인

## UI 및 편의 기능
- 자동 정리 완료 시 잠시 나타났다 사라지는 완료 알림 추가

## v2.2.5 — Vertex JSON 지원 및 모바일 설정 UI 개선

### ☁️ Vertex JSON 연결 추가

기존 Firebase AI 연결과 별도로, **Google Cloud 서비스 계정 JSON을 이용한 Vertex AI 직접 연결 방식**을 추가했습니다.

### JSON 지원 기능

* API 제공자 목록에 `Vertex JSON` 추가
* Google Cloud 서비스 계정 JSON 인증
* 서비스 계정 JWT 서명 및 OAuth 토큰 자동 발급
* 일반 AI 요약 지원
* 장기기억 2차 압축 지원
* 모델별 추론 설정 지원
* 토큰 사용량 및 예상 비용 표시
* JSON의 `project_id` 자동 사용
* 별도 Project ID 직접 지정 가능
* `global` 및 지역별 Vertex 엔드포인트 지원
* 인증 만료 또는 `401` 응답 시 토큰을 한 번 자동 갱신

### Vertex JSON 입력 방식

Vertex JSON을 선택하면 다음 두 가지 방식으로 서비스 계정 JSON을 등록할 수 있습니다.

* **JSON 입력 (세션)**  
  현재 요약 창에서만 사용하며 창을 완전히 닫으면 폐기됩니다.

* **JSON 저장/교체**  
  userscript 전용 GM 저장소에 보관하여 다음 실행에서도 사용할 수 있습니다.

저장된 JSON 원문은 설정 화면에 다시 표시하지 않습니다.

### Vertex 설정

* **Location**  
  기본값은 `global`입니다.

* **Project ID**  
  비워두면 서비스 계정 JSON의 `project_id`를 자동으로 사용합니다.

* **Gemini 3 계열**  
  Location 설정과 관계없이 지원되는 `global` 엔드포인트로 자동 연결합니다.

### 🔐 서비스 계정 JSON 보호

서비스 계정 JSON에는 장기 개인키가 포함되므로 일반 API Key보다 엄격하게 처리합니다.

* 서비스 계정 JSON을 페이지 `localStorage`에 저장하지 않음
* 저장된 JSON 원문을 페이지 입력창이나 DOM에 다시 표시하지 않음
* 브라우저 전용 입력창을 통해서만 JSON 입력
* 세션 입력과 영구 저장을 명확하게 분리
* 세션 종료 시 JSON과 발급된 토큰을 메모리에서 폐기
* OAuth 및 Vertex 요청 주소를 Google 공식 도메인으로 제한
* JSON, JWT 및 Access Token을 로그나 내보내기 파일에 포함하지 않음
* 저장된 JSON과 토큰을 직접 삭제할 수 있는 버튼 제공

> 서비스 계정 JSON은 장기 자격증명입니다.  
> Vertex AI 전용 서비스 계정을 만들고 필요한 최소 권한만 부여하는 것을 권장합니다.

### 🧠 Gemini 모델 호환성 개선

* 종료된 `gemini-3-pro-preview` 모델을 선택 목록에서 제거

* Gemini 3 계열에는 모델의 권장값과 충돌할 수 있는 이전 샘플링 설정을 전송하지 않도록 개선
* Vertex 모델과 Google Gemini 모델의 응답 및 사용량 처리를 통합
* Gemini의 내부 추론 파트와 실제 응답 텍스트를 구분하여 처리

### 🛡️ Firebase 설정 처리 개선

Vertex JSON 보안 처리와 함께 기존 Firebase 연결 방식의 설정 해석도 보강했습니다.

* 붙여넣은 Firebase 설정 코드를 직접 실행하지 않음
* 필요한 최상위 Firebase 설정값만 안전하게 추출
* 중첩된 가짜 설정이나 동적 함수 표현식을 설정으로 인식하지 않음
* 기존 Google, DeepSeek, OpenAI, Firebase 연결 기능 유지

### 📱 모바일 및 좁은 화면 설정 UI 개선

좁은 화면에서 설정 항목이 모두 세로로 쌓여 팝업이 지나치게 길어지던 문제를 개선했습니다.

820px 이하의 화면에서는 설정을 다음과 같이 배치합니다.

1. **API · 모델 · 턴 수**
2. **API Key / Firebase Script / Vertex 설정**
3. **요약 스타일 · 추론 · 내보내기**

### 세부 개선

* API, 모델, 턴 수를 같은 줄에 배치
* API Key 또는 Firebase Script 입력창은 다음 줄 전체 너비로 표시
* 요약 스타일, 추론, 내보내기를 같은 줄에 배치
* 모바일에서도 내보내기 버튼이 가로로 유지되도록 크기와 간격 조정
* Vertex의 Location과 Project ID를 좁은 화면에서도 2열로 유지
* 턴 수 안내 팝업이 화면 밖으로 벗어나지 않도록 오른쪽 정렬
* 520px 이하에서 설정이 다시 1열로 강제되던 기존 규칙 제거
* 넓은 PC 화면의 기존 설정 배치는 그대로 유지

설정 영역의 세로 길이를 줄여 작은 모바일 화면에서도 상단 닫기 버튼과 하단 작업 버튼에 더 쉽게 접근할 수 있도록 했습니다.

### 검증 화면 크기

* 320px
* 360px
* 390px
* 430px
* 690px

Google API Key, Firebase Script, Vertex JSON 화면을 각각 전환하여 설정 겹침과 가로 넘침이 없는 것을 확인했습니다.
