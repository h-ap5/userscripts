# 🌐 크랙 초월번역기

## 📌 업데이트 내역

### V4.2.3

- 번역문으로 교체하면 크랙이 직접 말풍선을 번역문으로 다시 그립니다. 교체 직후에도 코드 블록이 정상으로 보이고 크랙 `수정` 창도 번역문으로 열려서, 교체한 뒤 새로고침하지 않아도 됩니다. 이때는 크랙 화면 그대로라 `번역문 적용됨` 표시는 붙지 않습니다.
- 크랙 화면 내부를 찾지 못하면(크랙 업데이트 등) 지금처럼 번역문을 덮어 보여 줍니다. 이 경우에는 전처럼 교체 후 한 번 새로고침해 주세요.
- 모바일 브라우저처럼 확장 프로그램이 페이지와 분리되어 도는 환경에서도 작동하도록, 페이지에 작은 연결부를 넣어 크랙 화면을 맞춥니다.
- 지난 메시지의 OOC 문구를 자동으로 지우면, 화면의 내 말풍선에서도 새로고침 없이 바로 사라집니다.
- 앱체크 디버그 토큰 칸 옆에 `적용` 버튼을 넣었습니다. 토큰은 입력만으로는 저장하지 않고, `적용`(또는 `Enter`)을 눌러야 저장한 뒤 바로 한 번 받아 봅니다. 적용하기 전에는 상태 칸에 `앱체크 적용 전`을 표시합니다.
- 토큰 형식(8-4-4-4-12자리)이 아니면 저장하지 않고 알려 줍니다. 칸을 비우고 `적용`을 누르면 확인을 거쳐 저장된 토큰을 지웁니다. 제공자가 Firebase가 아니거나 Firebase 설정이 없으면 토큰만 저장해 두고 다음 번역 때 받습니다.

### V4.2.1

- Firebase 앱체크를 지원합니다. 2026년 11월 2일부터 Firebase AI는 앱체크 토큰이 없는 요청을 막기 때문에, 설정의 `API 연결`에서 Firebase를 고르면 `앱체크 디버그 토큰` 칸이 나타납니다.
- 디버그 토큰은 Firebase 콘솔 → 보안 → App Check → 앱 탭에서 Firebase 설정과 같은 웹앱의 `⋮` → `디버그 토큰 관리`로 만듭니다. 칸 옆 `i` 버튼에 같은 안내가 있습니다.
- 디버그 토큰은 탬퍼몽키 저장소에만 두고, 앱체크 토큰으로 바꾸는 요청도 페이지가 아닌 탬퍼몽키 요청으로만 보냅니다. 받은 앱체크 토큰(보통 1시간)은 만료 5분 전까지 탭과 새로고침을 넘어 다시 써서, 빡빡한 발급 한도에 덜 걸립니다.
- 키 상태 옆에 `앱체크 없음`·`앱체크 저장됨`·`앱체크 발급 완료`·`앱체크 실패`를 표시합니다. 토큰을 넣거나 바꾸면 바로 한 번 받아 보고, 실패하면 원인을 알림으로 보여 줍니다.
- 앱체크 실패 원인을 구분해 안내합니다. 발급 한도 초과(429), API 키의 웹사이트(리퍼러)·API 제한, 다른 웹앱에 등록된 토큰(403), 잘못된 값(400), 프로젝트·웹앱 없음(404), 서버 오류, 오래 쓰지 않아 꺼진 Firebase AI Logic을 각각 알려 줍니다.
- Firebase가 받아들이지 않은 앱체크 토큰은 바로 버리고 다음 번역 때 새로 받습니다. 디버그 토큰을 넣지 않으면 지금처럼 앱체크 없이 요청합니다.

### V4.2.0

- 번역기 화면을 전면 개편했습니다. 크랙 색·글꼴을 따르고 라이트·다크 테마에 맞춰 표시합니다. 쓰던 설정·API 키·지침 슬롯은 그대로 이어집니다.
- 번역 버튼을 꾹 누르면(PC는 우클릭도) `빠른 설정`이 열립니다. 모델·추론·번역 지침·말풍선 누르면 바로 교체·OOC를 그 자리에서 바꾸고 `이 답변 번역`으로 바로 번역하며, `전체 설정`으로 설정창을 엽니다. 짧게 누르면 전처럼 번역합니다.
- 설정창을 왼쪽 목록(번역·지침·OOC 자동 주입·키워드 치환·API 연결)과 오른쪽 내용으로 나눴습니다. 모바일은 목록에서 항목을 눌러 들어갑니다.
- 저장 버튼을 없애고 값을 바꾸면 바로 저장합니다. 제목 줄에 `저장 중…`·`저장됨`·`저장 안 됨`을 표시합니다.
- 추론은 모델 옆에서 최소·낮음·보통·높음 중 고르고, 2.5 계열은 추론 예산(128 이상)을 숫자로 넣습니다.
- 지침 슬롯 줄 끝의 `＋`로 지금 지침을 복사한 새 슬롯을 만들고, 기본 슬롯은 `기본 지침으로`, 커스텀 슬롯은 `지침 비우기`로 되돌립니다.
- 결과창을 새로 만들었습니다. 다시 번역한 결과가 `결과 1`·`결과 2`로 쌓여 전환할 수 있고, 지침·모델을 바꿔 다시 번역할 수 있습니다. 저장한 치환은 칩으로 눌러 바로 적용하고(`＋ 직접`으로 새 치환), `원문 보기`로 같은 자리에서 영어 원문을 확인합니다.
- 번역 버튼에서 상태를 바로 보여 줍니다. 번역 중, 지난 결과 있음(빨간 점), 교체됨(체크), 실패(느낌표)를 구분하고, 결과가 있는 버튼을 누르면 지난 결과가 다시 열립니다.
- 오류는 화면을 막지 않는 작은 알림으로 띄우고(PC는 아래, 모바일은 위), `자세히`에서 원인을 확인합니다. 결과마다 비용을 보여 주고 `i` 버튼에서 계산 방식을 설명합니다.
- 설정마다 `i` 버튼으로 짧은 설명을 볼 수 있고, API 키 칸에 보기/숨기기 버튼과 `키 저장됨`·`키 없음` 표시를 넣었습니다.

### V4.1.9

- 상태창처럼 코드 블록이 있는 답변을 교체하면 번역문이 말풍선에 바로 표시되지 않던 문제를 수정했습니다. 크랙이 코드 블록 위에 그리는 언어 이름 머리글(`info` 등)을 말풍선 글로 읽어 원문이 바뀐 것으로 판단하던 부분을 고쳤습니다.
- 교체 직전 말풍선에 보이던 글도 원문으로 기억합니다. 크랙이 원문과 다르게 그리는 글자(수식, 이름 치환 등)나 브라우저 번역·다른 확장 프로그램이 바꿔 둔 말풍선에서도 교체한 번역문을 표시합니다.
- 같은 결과창에서 한 번 교체한 뒤 다른 번역 결과로 다시 교체하면 `서버의 원문이 변경되었습니다`로 막히던 문제를 수정했습니다.
- 같은 자리에 다른 답변(리롤 버전 등)이 그려지면 그 말풍선에는 번역문을 덮어 표시하지 않습니다.
- 크랙이 이미 말풍선을 번역문으로 다시 그린 경우를 표시 실패로 알리지 않습니다.
- `화면 표시 다시 시도`를 눌렀을 때 말풍선 내용이 이미 바뀌었다면, 실패 대신 `말풍선 내용이 이미 바뀌었습니다. 번역문이 보이지 않으면 새로고침해주세요.`라고 안내합니다.

### V4.1.8

- 브라우저 기본 `alert`·`confirm` 창을 번역기 전용 알림·확인 창으로 바꿨습니다. 기본 창처럼 탭 전체(다른 확장 프로그램 포함)를 멈추지 않고, 크랙 라이트·다크 테마를 따르며, 알림이 여러 개면 차례로 표시합니다.
- 알림·확인 창은 `Enter`로 확인, `Esc`로 취소·닫기를 지원하고, 이 키가 크랙 단축키(입력창 이동·요약 메모리)로 넘어가지 않습니다. 지침서 초기화처럼 되돌리기 어려운 확인은 `취소` 버튼에 먼저 초점을 둡니다.
- Google·DeepSeek 응답이 끊기면 `이미 번역이 진행 중` 상태로 계속 막히던 문제를 수정했습니다. 3분 동안 응답이 없으면 요청을 중단하고 안내합니다.
- Google API 응답이 여러 조각으로 올 때 첫 조각만 사용해 번역이 잘리던 문제를 수정했습니다. 생각(thought) 부분을 뺀 본문 조각을 모두 이어 붙입니다.
- 번역이 길이 제한에 걸려 잘리면 팝업에서는 끝부분을 확인하라는 경고를 띄우고, 즉시 교체에서는 원문을 그대로 두고 교체하지 않습니다.
- 차단되었거나 비어 있는 번역 결과, 결과창에서 모두 지운 번역문으로는 교체하지 않습니다. 이전에는 즉시 교체 시 원문이 빈 글로 덮어써질 수 있었습니다. 응답을 읽지 못하면 `Google 응답을 읽지 못했습니다 (HTTP 502).`처럼 원인을 표시합니다.
- 대화 내용에 HTML이 섞여 있을 때 말풍선 비교 과정에서 그 HTML(예: `<img onerror>`)이 크랙 페이지에서 실행될 수 있던 문제를 수정했습니다.
- 여러 줄로 된 OOC 문구가 지난 메시지에서 자동 삭제되지 않던 문제를 수정했습니다. 삭제 요청 사이에 간격을 두고, 실패한 정리는 다음 전송 때 다시 시도합니다.
- 수정으로 원문이 바뀐 말풍선에서는 예전 번역 결과를 다시 열지 않습니다.
- 번역문을 교체한 뒤 가만히 있어도 교체한 답변을 계속 다시 읽던 반복 작업을 없앴습니다. 새 답변이 나오는 동안에는 내용이 바뀐 말풍선만 다시 맞추고, 번역 버튼 상태는 결과가 저장된 말풍선에서만 확인합니다.
- 크랙 화면 준비(React hydration)가 끝나기 전에 버튼을 넣어 화면 전체가 다시 그려지던 문제를 막았습니다. 채팅 화면 안의 버튼·사이드바 메뉴는 준비가 끝난 뒤(최대 8초 대기) 붙입니다.
- 과거 답변을 여러 페이지 조회할 때 요청 사이에 20ms 간격을 두어 요청이 한꺼번에 몰리지 않게 했습니다.

### V4.1.7

- 말풍선의 메시지 ID로 `GET /messages/{id}` 단건 조회를 먼저 시도하고, 단건 조회를 지원하지 않거나 `404`가 반환될 때만 `nextCursor` 페이지 검색으로 전환합니다.
- 페이지 검색은 한 번에 50개씩 최대 32페이지까지 진행하며, 같은 cursor가 반복되면 즉시 중단해 오래된 답변 탐색 중 무한 요청이 생기지 않도록 했습니다.
- 리롤로 한 말풍선에 여러 message ID가 남아 있어도 현재 화면에 보이는 답변과 가장 잘 맞는 ID를 선택합니다.
- 이미 번역문으로 교체한 말풍선을 다시 눌렀을 때 서버의 번역문이 아니라 최초 영문 원문으로 재번역합니다. 화면 재마운트로 임시 표시 정보가 사라진 경우에도 최초 원문을 별도로 보존합니다.
- 실제 교체 직전에는 정확한 primary message ID만 다시 확인하고, 유사도 검색으로 다른 답변을 잘못 교체하지 않도록 했습니다.
- 답변 생성 직후에는 같은 ID와 서버 내용이 두 번 연속 안정된 것을 확인한 뒤 번역하며, 기존 진단 출력과 모바일 Edge 보호 로직을 유지합니다.

- 번역본으로 메시지를 교체한 뒤 새로고침하지 않아도 현재 말풍선에 즉시 반영되도록 변경했습니다. 마크다운 서식은 유지하고 위험한 HTML은 제거합니다.
- 번역할 답변을 찾는 방식을 개선했습니다. 이전 답변, 스트리밍 중인 답변, 링크·코드 블록이 포함된 답변, 모바일·PC용 요소가 겹친 경우에도 사용자가 누른 답변을 우선 확인하며 다른 메시지가 잘못 교체되지 않도록 했습니다.
- `번역 방식`에 커스텀 슬롯 기능을 추가했습니다. 슬롯별 제목과 전용 번역 지침을 만들 수 있으며, 입력한 내용과 마지막 선택 슬롯은 현재 브라우저에 자동 저장됩니다.
- 커스텀 슬롯 추가·삭제·삭제 취소를 지원하고, 설정창과 번역 결과창의 드롭다운에서 저장한 슬롯을 빠르게 전환할 수 있습니다.
- 동일한 답변을 연속으로 교체하는 동작을 차단했습니다. 서버 저장에는 성공했지만 현재 화면에 표시하지 못한 경우에는 API를 다시 호출하지 않고 `화면 표시 다시 시도`로 복구할 수 있습니다.

- 알려진 주의사항

- 교체 직후의 말풍선은 임시 미리보기이므로 코드 블록이 깨져 보일 수 있습니다. 저장된 번역문 자체가 깨진 것은 아니며, 페이지를 새로고침하면 정상 표시됩니다.
- 교체 후 새로고침하기 전에 크랙의 `수정`을 누르면 편집창에 번역 전 영문이나 이전 내용이 나타날 수 있습니다. 이 상태로 저장하면 번역이 이전 내용으로 롤백될 수 있으므로, **번역문 교체 → 페이지 새로고침 → 수정** 순서로 사용해 주세요.
